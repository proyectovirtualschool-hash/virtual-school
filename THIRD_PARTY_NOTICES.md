# Avisos de terceros

El digitalizador usa componentes open source. Verifica siempre la licencia vigente en el repositorio oficial de cada proyecto antes de redistribuir.

| Componente | Uso | Licencia declarada |
| --- | --- | --- |
| `@huggingface/transformers` (Transformers.js) | Inferencia local del modelo TrOCR | Apache-2.0 |
| `Xenova/trocr-small-handwritten` | Modelo de reconocimiento de escritura manuscrita | MIT (modelo base Microsoft TrOCR) |
| `onnxruntime-web` | Runtime WASM para TrOCR | MIT |
| `tesseract.js` | OCR de texto impreso y apoyo en manuscrito | Apache-2.0 |
| `tesseract.js-core` | Núcleos WASM de Tesseract | Apache-2.0 |
| `@tesseract.js-data/spa` | Datos de idioma español | Apache-2.0 |
| `@techstark/opencv-js` / OpenCV | Mejora de imagen y detección de tabla | Apache-2.0 |
| `pdfjs-dist` (PDF.js) | Render de PDF a imagen | Apache-2.0 |

Las marcas y nombres de terceros pertenecen a sus respectivos titulares.
